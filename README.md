# Домашнее задание: Фаза 1, Фаза 2, Прямой Симплекс Метод

Реализованы обе фазы симлекс-метода (внутри использовано правило Блэнда для предотвращения зацикливания).
Для обновления базисной матрицы используется LU-разложение. В самом начале используем `LuFactors(pvec, L, U)` - LU-факторизацию базисной матрицы (инициализируем объект класса `LuFactors`), 
далее ее обновление просиходит с помощью метода Бартельса-Голуба, в частности с помощью функции `bg_replace_col`.

Допуски: `eps_rc`=1e-9, `eps_dir`=1e-12, `eps_phase1`=1e-9; 
`abs(pivot)` < 1e-12 -> полная LU-рефакторизация.
